## Name

Aida64SD

## Short description

Live AIDA64 sensor readings on your Stream Deck, as graphs and text.

## Description

Show live AIDA64 sensor readings on Stream Deck keys: temperatures,
voltages, fan speeds, power, clocks, usage and throughput, as a graph, text,
or both.

- Sensor: one reading per key, with per-tile colours, scale (or auto range)
  and number format.
- Composite: up to four readings stacked on one key.
- Derived: sum, average, max, min, difference or percentage of several
  readings, as a new metric.
- Thresholds: recolour a tile and show alert text when a reading crosses a
  limit, per tile or from a shared library.
- Dial Carousel: cycle readings on a Stream Deck+ dial.
- Settings: one key for the refresh rate (or follow AIDA64's own update rate
  automatically), the AIDA64 connection status and the threshold library.

Requires Windows 10 or later, Stream Deck 6.9 or later, and AIDA64 (Extreme,
Engineer or Business) with shared memory enabled (AIDA64: File > Preferences >
Hardware Monitoring > External Applications > Enable shared memory).
